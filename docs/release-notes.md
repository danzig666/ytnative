ytnative is SmartTube ported to LG webOS: a native, ad-free YouTube client for the TV.

**Install:** add `https://danzig666.github.io/ytnative/api/apps.json` as a repository in the
[webOS Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) (Settings > Add
repository), or install the `.ipk` below with `ares-install`. Root is not required.

**Files:** the `.ipk` package, its Homebrew Channel manifest and `repo.json`, `SHA256SUMS`, and the
unstripped binary (`.debug`) for symbolizing crash logs.

See the [README](https://github.com/danzig666/ytnative#readme) for the feature list.
